# 数据埋点表（key → value｜方案稿）

> MVP 清单项。事件名可调整；**未接入埋点系统**。

## 1. 公共字段（所有事件）

| key | value 说明 | 类型 |
| --- | --- | --- |
| event | 事件名 | string |
| ts | 客户端／服务端时间戳 | int |
| sid | 会话 ID | string |
| uid_hash | 用户标识哈希 | string |
| entry_id | jtalk 入口 | string |
| dh_enabled | 是否数字人服务中 | bool |
| agent_enabled | 本轮是否开 Agent | bool |
| ab_bucket | 灰度桶 | string |
| app_ver | 容器版本 | string |

## 2. 事件明细

| event | 触发时机 | 关键 value 字段 |
| --- | --- | --- |
| dh_guide_show | 引导浮层／卡片展示 | guide_type=float\|card |
| dh_guide_click | 点击进入数字人 | guide_type |
| dh_guide_dismiss | 关闭引导 | guide_type |
| dh_init_start | 开始 init | dProfileKey |
| dh_init_success | Room 就绪 | room_id_hash, cost_ms |
| dh_init_fail | 初始化失败 | error_code, stage |
| dh_limit_reject | 限流拒接 | reason=room_cap |
| dh_av_start | 收到推流开始 | lag_ms_from_graphic |
| dh_sync_fallback_2s | 2s 降级出图文 | waited_ms |
| dh_interrupt | 打断发生 | from_type, to_type |
| dh_user_input | 用户发送 | modality=voice\|text, asr_ok? |
| dh_agent_request | 调用 Agent | timeout_ms |
| dh_agent_ok | Agent 校验通过 | latency_ms, tool_count |
| dh_agent_fail | 失败／跳过 | reason=timeout\|validate\|off |
| dh_nlp_answer | 图文答案就绪 | faq_id? |
| dh_transfer_human | 转人工 | by=user\|system\|suggest |
| dh_rate_submit | 提交评价 | rate_type=dh\|bot\|human, score |
| dh_session_flag | 会话标记变更 | dh_service=true\|false |

## 3. 隐私

- 不埋口播全文、不埋证件号；需要内容质检走独立合规通道。  
- uid 仅哈希；room_id 哈希。
