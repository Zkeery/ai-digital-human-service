# 检索与重排组件说明（LLM／EM／Rerank）

## 1. 链路

```text
query →（可选改写）→ Embedding 检索 TopN →（可选 Rerank TopK）→ 拼接证据 → LLM 生成 → 校验
```

## 2. 组件职责

| 组件 | 职责 | 失败策略 |
| --- | --- | --- |
| LLM 改写 | 可选，多问法归一 | 跳过改写 |
| EM | 向量召回 | 回退纯 FAQ |
| Rerank | 精排 | 跳过，用向量序 |
| LLM 生成 | 基于证据作答 | 关 RAG，回 NLP |

## 3. 参数初值（待调）

- TopN＝20，TopK＝5，最大证据字符数＝2k  
- 分数阈值：低于则 `should_refuse` 或转人工建议  

## 4. 一期态度

**默认不启用 RAG**；文档齐备为二期开工条件。
