# 用户调研报告（方案初稿）

> 应含访谈／问卷。本批无实地样本，给出**调研设计＋假设洞察**，待执行后回填。  
> **业务线**：零售金融客服数字人。

## 1. 调研目标

验证用户对「金融数字人客服」的接受度、信任、打断与转人工预期，以及对涉资金／身份问题的安全感诉求；以及运营对分流／评价的诉求。

## 3. 访谈提纲（摘要）

1. 更想「看数字人说话」还是「快速看文字」？  
2. 什么情况下会立刻转人工？  
3. 口播卡顿／只出图文时能否接受？  
4. 是否需要明确告知「非真人」？  
5. 语音输入准确率差时的行为？  

运营侧：分流误伤、评价口径、会话检索「是否数字人」。

## 4. 问卷核心指标（草案）

- 意愿使用数字人：5 点量表  
- 信任度／亲和度  
- 可接受等待（秒）  
- 失败后期望：图文／重试／人工  

## 5. 基于基线 PRD 的假设洞察（未验证）

| 假设 | 产品含义 |
| --- | --- |
| 用户要结果多于要形象 | 2s 图文降级必须保留 |
| 限流／失败体验决定口碑 | 异常弹窗文案需走查 |
| 运营要筛选数字人会话 | 会话标记与消息类型保留 |
