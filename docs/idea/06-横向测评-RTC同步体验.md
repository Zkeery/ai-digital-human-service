# 横向测评研究报告 · RTC 与图文同步体验

> 横向测评 N 份之三。关注「听得到且看得到答案」的同步策略。

## 1. 同步策略候选

| 策略 | 描述 | 基线 |
| --- | --- | --- |
| Hold-until-av | 图文等推流开始再展示 | 基线采用 |
| Text-first | 先图文后声音 | 非默认 |
| Dual-independent | 各走各的 | 易不一致，不推荐 |
| Timeout-fallback | Hold＋超时出图文 | 基线 2s |

## 2. 体验维度

| 维度 | Hold+2s | Text-first | Dual |
| --- | --- | --- | --- |
| 一致性 | 高 | 中 | 低 |
| 首答等待 | 中 | 低 | 低 |
| 实现复杂度 | 中 | 低 | 低 |
| 与口播品牌感 | 高 | 中 | 低 |

## 3. 结论

**保持 Hold＋2s 降级**；Agent 不得另起一套等待文案破坏该契约。Text-first 仅作实验开关（未来 POC）。

## 4. 待实测指标

- P50／P95：推流开始通知耗时  
- 2s 降级触发率  
- 用户「有声无文／有文无声」投诉率
