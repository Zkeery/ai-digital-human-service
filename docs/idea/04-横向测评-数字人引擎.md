# 横向测评研究报告 · 数字人引擎／形象驱动

> 横向测评 N 份之一。方案级对比维度表，**未做实测打分**。

## 1. 测评目的

为未来 POC 选型数字人引擎（形象驱动＋TTS 对接＋RTC）准备维度，不在本批定标厂商。

## 2. 候选类型（类别，非厂商承诺）

| 类型 | 描述 | 备注 |
| --- | --- | --- |
| A 现网引擎 | 基线已接（如言犀等，以现网为准） | **推荐默认** |
| B 云端数字人 PaaS | 供应商托管渲染与推流 | 合同／出境评估 |
| C 端侧轻量形象 | 端上驱动＋云端 TTS | 弱设备风险 |

## 3. 对比维度

| 维度 | 权重建议 | A 现网 | B PaaS | C 端侧 |
| --- | --- | --- | --- | --- |
| 与 jtalk 已有对接成本 | 高 | 优 | 中 | 中低 |
| 口型／动作可控（指令 ID） | 高 | 待确认 | 看 API | 弱 |
| Room／并发与限流 | 高 | 已知有策略 | 待测 | 端侧压力 |
| 时延（首帧／首包语音） | 高 | 待测 | 待测 | 待测 |
| 合规与数据驻留 | 高 | 待确认 | 重点评估 | 较好控 |
| 成本模型 | 中 | 已知摊销 | 按量 | 研发摊销 |
| 换形象／换肤 | 中 | 4 形象基线 | 通常强 | 视资源 |

## 4. 初步建议

POC 前 **默认 A**；仅当现网无法满足口型／并发时开 B 的并列 POC（另立项）。

## 5. 实测计划（未执行）
