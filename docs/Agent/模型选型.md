# Agent 模型选型（方案）

## 1. 选型原则

1. 国内可合规部署／调用（待确认具体区域要求）  
2. 强结构化输出能力  
3. 时延可纳入用户等待预算  
4. 成本可控；可关断  
5. **不得**因选型绑定不可降级的数字人引擎  

## 2. 候选画像（类别）

| 候选 | 适用 | 主要风险 |
| --- | --- | --- |
| 低时延对话模型 | 在线 compose | 复杂推理弱 |
| 强推理模型 | 难例 | 时延／成本高 |
| 现网已有 NLP 仅润色 | 最小改动 | 提升有限 |

## 3. 推荐（方案）

- 默认路径：现网 NLP／FAQ（S0）  
- Agent 灰度：待模型评测后在「低时延对话模型」中择一  
- 难例不阻塞主链路：超时回退
