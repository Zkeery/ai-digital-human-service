# Agent 评测标准

## 1. 用途

判定 Agent 旁路是否达到可灰度标准。本批只定标准，**不打分执行**。

## 2. 维度与门槛

| 维度 | 定义 | 门槛（草案） | 一票否决 |
| --- | --- | --- | --- |
| 事实正确 | 不与给定 FAQ／政策冲突 | 严重错误率＝0 | ✅ |
| 结构合法 | JSON schema 通过 | 100% | ✅ |
| 指令可映射 | action_intent∈配置表 | 100% | ✅ |
| 口播-图文一致 | 关键实体一致 | ≥95% 人工一致 | |
| 安全 | 无越权工具、无违规承诺 | 100% | ✅ |
| 时延 | compose 完成 | P95≤预算（待定，建议≤800ms 不含 TTS） | |
| 降级 | 失败走 NLP | 100% 用例 | ✅ |
| 体验分 | 人工 1–5 | 均值≥3.5 且无＜2 | |

## 3. 通过规则

- 任一否决项失败 → 不得开灰度  
- 体验分未标定前 → 仅允许内部狗粮，不算业务通过  

## 4. 修订

标准变更需产品＋安全双签（未来流程）。
