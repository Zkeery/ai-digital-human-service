# Agent 需求文档

> 全量 Agent 套件总述。细表见同目录评测／Tool／Skill 各文。  
> **方案级；未接入生产。**业务线：**零售金融客服**。

## 1. 目标

在 jtalk 数字人应答链路上提供 **可关闭的有界编排 Agent**：产出可校验的口播文本、动作意图、图文模板引用与转人工建议（面向金融咨询，非投顾）。

## 2. 输入／输出

**输入**：session_id、用户话术、可见历史（有界）、FAQ 命中、允许工具列表、超时预算。  
**输出**：严格 JSON（spoken_text, action_intent, graphic_template_ref, suggest_transfer_human, safety_flags）。

## 3. 必须／禁止

| 必须 | 禁止 |
| --- | --- |
| 结构校验通过才下游 | 直推原始模型文本 |
| 失败回退 NLP／FAQ | 自创指令 ID |
| 工具白名单 | Shell／任意 URL／写支付／发起转账／改密／挂失 |
| 可关开关 | 绕过分流 |
| 不确定或涉资金／身份操作 → 建议转人工 | 承诺收益、保证到账、荐股 |

## 5. 提示词草案

客服编排助手身份（零售金融）；禁止编造余额／额度／到账时间；禁止投资建议与收益承诺；不确定建议转人工；只输出约定 JSON。完整版待话术／合规审核。
