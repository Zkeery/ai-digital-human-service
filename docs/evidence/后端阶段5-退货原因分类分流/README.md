## 产品经理怎么验（http://127.0.0.1:3050/）

1. 怎么退货？ → 问原因  
2. 尺码不合适 → 提到换货可能；回「想换货」→ 换货指引（仍无退货申请步骤）  
3. 新会话：质量有问题 → 「确认退货」→ 才出现申请步骤  
4. （可选）发错货 → 「要补发」；或「转人工」→ 提示点页面转人工，会话仍可聊
