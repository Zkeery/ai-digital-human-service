# 前端第 6 阶段 · 开场加查物流 · 技术开发文档

> **线路：前端。**  
> 承接后端第 8 阶段物流发货查询。只改开场快捷入口列表。不上线。

## 一、目标（产品话）

开始咨询后，开场多一个 **查物流**：一点就发「查物流」，进入后端物流澄清（已发货查轨迹／还没发货催一下），少打字。

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 开场芯片 | `STARTER_QUICK_REPLIES` 增加「查物流」 |
| 点击 | 复用现有 `onSend("查物流")` |
| 单测 | 断言开场列表含「查物流」 |
| 关键文件 | `frontend/features/session/quickReplies.ts` · `frontend/tests/quick-replies.test.ts` |

### 不做

- 改后端物流状态机  
- 新页面、视觉大改、真物流接口  

## 三、通过条件

1. 开始咨询可见「查物流」  
2. 点后出现「已经发货查轨迹／还没发货催一下」等澄清按钮  
3. vitest／typecheck／build 通过  

## 四、验收清单（3050）

1. 开始咨询 → 看到「查物流」  
2. 点「查物流」→ 出现物流澄清选项  
3. 点「已经发货查轨迹」→ 听到轨迹说明  

## 五、完成定义

手测通过后完成。证据见 `docs/evidence/前端第6阶段/`。
