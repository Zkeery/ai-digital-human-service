# 后端第 18 阶段 · 价保咨询 · 技术开发文档

> **线路：后端。** 不上线、不查真价保单／不改价。  
> 前端开场加「价保」见 **前端第 17 阶段**。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。

## 一、目标（产品话）

用户问价保／保价时，先短问一句，再分流：

1. **怎么申请** → 入口短指引  
2. **适用条件** → 时限／规则短说明  
3. **差价没到** → 留证、转人工  
4. 可点快捷选项  

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 状态 | `price_protect_flow`：`idle`／`awaiting_clarify` |
| 触发 | 价保、保价、价格保护、降价补差 等（其它多轮进行中不抢） |
| 分支 | 怎么申请／适用条件／差价没到／转人工 |
| 关键文件 | `price_protect_dialogue.py` · `sessions.py` · 各对话 pack · `test_stage18_price_protect.py` |

### 不做

- 真算差价、改价、接促销／价保系统  

## 三、状态机

```text
idle → 问价保 → awaiting_clarify
  ├─ 怎么申请 → 短指引 → idle
  ├─ 适用条件 → 短指引 → idle
  ├─ 差价没到 → 短指引＋转人工 → idle
  └─ 转人工 → 建议转人工 → idle
```

## 话术原则

- 澄清一句口语；分支短答，不复读选项名  

## 四、通过条件

1. 「价保」→ 短澄清 + 选项  
2. 「差价没到」→ suggest 转人工，不复读开头  
3. pytest 全绿

开场点「价保」走完路径。
