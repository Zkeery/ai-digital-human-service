# 近程 C1 · RAG 最小闭环 · 技术开发文档

> 对应 PRD V0.4 N4；决策见 [近程增强-决策纪要](./近程增强-决策纪要.md)。  
> 知识范围见 [RAG 知识结构设计表](../RAG/知识结构设计表.md)。**不上线**。

## 一、目标（产品语言）

本地打开「知识检索」后：

1. 问**网点／营业时间**或**理财说明书**相关时，口播可带上**公开演示样例依据**  
2. 关掉检索 → 行为与现在一样，只走规则多轮  
3. 检索超时或找不到样例 → **不编造**，继续用原来的规则话术  

本阶段**不用**付费 Embedding／外挂向量库（省月费、可离线演示）；C2 再冻结算例门禁。

## 二、已锁定决策

| 项 | 结论 |
| --- | --- |
| 首批知识 | 网点／营业时间＋理财说明书公开摘要（Q8=A） |
| 可关 | 验收模式「打开／关闭 RAG」；默认关，避免改旧验收基线 |
| 失败策略 | 超时／未命中 → 回退规则；禁止编造政策 |
| 材料 | 仅仓库内公开演示切片，无工单原文 |

## 三、范围

| 改 | 不改 |
| --- | --- |
| 本地样例切片＋词法检索 | 外网向量库／Embedding 计费调用 |
| `rag_enabled` 配置与事件 `dh_rag_hit`／`miss`／`skip` | C2 样例冻结打分 |
| 命中时在规则口播后附加「样例依据」 | 访客看到 RAG 开关 |
| 未走规则且检索命中时，用样例组答 | 替换既有网点／理财多轮澄清流程 |

## 四、逻辑

1. 先跑现有金融多轮／FAQ／Agent（不变）。  
2. 若 `rag_enabled`：对用户原文做本地检索（限时）。  
3. **命中**且当前答是网点／理财「实质回答」（非澄清）：口播末尾追加样例依据；记 `dh_rag_hit`。  
4. **命中**且前面没有规则答（走了兜底）：用样例组一口播；`source=rag`。  
5. **未命中** → `dh_rag_miss`，口播不变。  
6. **超时／关闭** → `dh_rag_skip`（关闭时仅对相关主题记一次跳过，避免刷屏）。

## 五、接口

### `GET/PUT /api/v1/config`

增加：

- `rag_enabled: bool`  
- PUT 可传 `rag_enabled`

### 事件

| event_key | 含义 |
| --- | --- |
| `dh_rag_hit` | 命中；payload含 `chunk_id`／`collection` |
| `dh_rag_miss` | 未命中 |
| `dh_rag_skip` | 关闭或超时；payload含 `reason` |

## 七、产品经理验收（照着点）

1. http://127.0.0.1:3050/ 强制刷新  
2. **访客模式**：看不到 RAG 开关  
3. **验收模式** →「打开 RAG」  
4. 创建会话 → 问「网点营业时间」或点走查里网点相关  
   - 口播里应出现「样例依据」或演示网点时间字样  
   - 事件时间线有 `dh_rag_hit`  
5. 「关闭 RAG」再问同样问题 → 仍有规则答，但无新的样例依据追加；可出现 `dh_rag_skip`  
6. 问无关闲聊 → 不编造网点政策
