# 后端第 17 阶段 · 会员积分咨询 · 技术开发文档

> **线路：后端。** 不上线、不查真积分账本。  
> 前端开场加「会员积分」见 **前端第 16 阶段**。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。

## 一、目标（产品话）

用户问会员／积分时，先短问一句，再分流：

1. **查积分** → 哪里看余额  
2. **怎么用** → 抵扣／兑换短指引  
3. **积分不对** → 留证、转人工  
4. 可点快捷选项  

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 状态 | `points_flow`：`idle`／`awaiting_clarify` |
| 触发 | 会员积分、积分、会员 等（其它多轮进行中不抢） |
| 分支 | 查积分／怎么用／积分不对／转人工 |
| 关键文件 | `points_dialogue.py` · `sessions.py` · 各对话 pack · `test_stage17_points.py` |

### 不做

- 真改积分、发会员等级、接 CRM  

## 三、状态机

```text
idle → 问会员积分 → awaiting_clarify
  ├─ 查积分 → 短指引 → idle
  ├─ 怎么用 → 短指引 → idle
  ├─ 积分不对 → 短指引＋转人工 → idle
  └─ 转人工 → 建议转人工 → idle
```

## 话术原则

- 澄清一句口语；分支短答，不复读选项名  

## 四、通过条件

1. 「会员积分」→ 短澄清 + 选项  
2. 「积分不对」→ suggest 转人工，不复读开头  
3. pytest 全绿

开场点「会员积分」走完路径。
