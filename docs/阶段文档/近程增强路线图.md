# 近程增强路线图（本地 · 不上线）

> 依据 PRD V0.4。产品经理 2026-10-03：除上线外启动近程增强。  
> 决策已确认（见 [近程增强-决策纪要](./近程增强-决策纪要.md)）。

## 总原则

1. **一律本地演示**（前端 3050／后端 8050），不挂公网、不接现网账号。  
2. **一次只开一个主阶段**：文档 → 代码 → 自动化 → 手测 → 证据包 → 再开下一阶段。  
3. **配置不对客户露脸**：入口选择、Agent 总闸、入口级 Agent 等只在验收模式或服务端配置；访客壳只呈现咨询体验。  
4. 密钥不进仓库；RAG／模型调用受月费上限（≤ ¥500）约束。  
5. 金融高风险动作规则不变：不代客操作、不承诺收益、不查真账。
