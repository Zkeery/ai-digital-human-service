# 前端第 9 阶段 · 开场加改地址 · 技术开发文档

> **线路：前端。**  
> 承接后端第 10 阶段修改收货地址。只改开场快捷入口。不上线。

## 一、目标（产品话）

开场增加 **改地址**：一点就发「改地址」，进入后端地址澄清（还没发货／已经发货），少打字。

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 开场芯片 | `STARTER_QUICK_REPLIES` 增加「改地址」 |
| 点击 | 复用现有 `onSend("改地址")` |
| 单测 | 断言开场列表含「改地址」 |
| 关键文件 | `frontend/features/session/quickReplies.ts` · `frontend/tests/quick-replies.test.ts` |

### 不做

- 改后端地址状态机  
- 真改址接口、地图选点、上线  

## 三、通过条件

1. 开始咨询可见「改地址」  
2. 点后出现「还没发货／已经发货」澄清按钮  
3. vitest／typecheck／build 通过  

## 四、验收清单（3050）

1. 开始咨询 → 看到「改地址」  
2. 点「改地址」→ 出现发货状态澄清  
3. 点「还没发货」→ 听到自助改址说明  

## 五、完成定义

手测通过后完成。证据见 `docs/evidence/前端第9阶段/`。
