# AI数字人客服 · 前端适配声明

> 承接《技术适配声明》；本文件只定前端边界。不上线、不接真 RTC。  
> **业务线**：零售金融客服（2026-10-02）。

## 1. 产品形态

- **本阶段交付**：本地可演示的前端（端口 **3050**），对接已有后端 **8050**。
- **不是**：jtalk 现网蒙层、真数字人推流、云部署。
- **数字人展示**：占位形象区（选肤／状态文案），推流仍走后端契约桩。
- **行业话术**：展示金融咨询多轮；电商开场入口样例已归档，不再扩展。

## 2. 技术选型（手册默认）

| 项 | 选定 |
| --- | --- |
| 框架 | Next.js App Router + TypeScript |
| 样式 | Tailwind + CSS 变量 |
| 端口 | 3050 |
| API | 浏览器直连 `http://127.0.0.1:8050`（`NEXT_PUBLIC_API_BASE`） |
| 密钥 | 前端不持有 LLM／引擎 Key |

## 3. 视觉方向（推荐已定）

- C 端客服对话布局：上／左为数字人占位，下／右为对话与操作。
- 主色青绿系（延续联调页认可的方向），非运营大盘风。
- 桌面与手机宽度都要能走完主路径。

## 4. 本阶段必做／不做

**必做**：建会话、引导、Agent 开关、发消息、初始化 Room、推流、开始展示、2s 降级提示、转人工确认、评价、历史、换肤试验。

**不做**：上线、登录体系、真 RTC、多入口运营台、RAG。

## 5. 本地 MVP 收口与近程（2026-10-03）

- **状态**：前端本地 MVP **已交付**（访客主路径 + 验收辅助），详见 [前端本地MVP收口](../MVP/前端本地MVP收口.md)。
- **已覆盖补充体验**：一屏访客壳、数字人画面放大、输入聚焦、复制回复／本轮对话、复制失败白话提示、失败重试、埋点骨架、走查快捷条等（前端第20～41）。
- **近程将接**：多入口切换、入口级换肤／Agent、统计面板、RAG 结果展示（见 [近程增强路线图](./近程增强路线图.md)；**仍不上线**）。
- **仍不做**：真 RTC／现网运营台。

## 6. 与联调页关系

- `http://127.0.0.1:8050/` 静态联调页保留给验收探针。
- **产品演示优先用 3050 前端。**
