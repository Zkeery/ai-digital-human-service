# 前端第 38 阶段 · 输入自动聚焦 · 技术开发文档

## 一、目标

开始咨询后、以及客服回复锁定解除后，输入框自动获得焦点，减少再点一次才能打字。

## 二、范围

| 改 | 不改 |
| --- | --- |
| `shouldAutoFocusComposer` 规则 | 后端、API |
| `ChatPanel` 文本框 ref 与聚焦时机 | 打断发送规则 |
| | 上线／多入口 |

## 三、验收

1. 3050 点「开始咨询」→ 欢迎语出来后，光标在输入框内（可直接打字）  
2. 发送「查余额」→ 回复中输入禁用 → 回复结束后光标回到输入框  
3. 回复进行中不抢焦点到别处  
4. `npm test` 全过
