# 前端第 2 阶段 · 技术开发文档

> 只覆盖本阶段。承接第 1 阶段已验收的 3050 工作台。  
> **不上线、不接真 RTC／现网 jtalk 蒙层、不改后端业务契约**（除非 CORS／纯展示所需的无破坏兼容小改）。

## 一、目标（产品话）

把第 1 阶段「什么按钮都露在外面的验收台」，收成更像 **C 端客服对话** 的演示页：

1. **访客模式（默认）**：用户只看到数字人占位、对话、发送、转人工、评价；**看不到 Agent 开关**与推流／特殊指令等技术按钮。  
2. **验收模式**：用页面角落入口打开，露出 Agent 开关、推流、开始展示、降级模拟、特殊指令等（给产品经理／开发验收）。  
3. **主路径更省事**：访客点「开始咨询」后，自动完成建会话 → 引导 → 初始化默认形象（仍可换肤）；发消息后可选自动推流排队（契约桩），降级时只出现友好黄条。  
4. **转人工须确认**：点转人工先弹确认，避免误触；确认后会话结束且输入禁用。

验收地址仍为：**http://127.0.0.1:3050/**（后端 **8050**）。

## 二、范围边界

### 本阶段做

| 项 | 说明 |
| --- | --- |
| 双模式 UI | `guest`（默认）／`lab`（验收）；模式存 `sessionStorage`，刷新保持 |
| 隐藏 C 端不该见的控件 | Agent 开关节、llm_mock 细项、推流／started／check-sync／特殊指令仅 lab |
| 开始咨询一键流 | guest：一键建会话＋引导＋init（默认形象 001） |
| 发送后体验 | guest：发送成功后自动 `push`；不强制自动 `stream-started`（避免静默挡 NLP）；lab 保留手动推流／开始展示 |
| 转人工确认 | 确认对话框；文案说明「将结束数字人咨询」 |
| 状态分层 | 加载中／空会话／失败横幅分开，禁止用转圈代替错误 |
| 窄屏 | ≥390px 宽主路径可点完；数字人区在上、对话在下 |
| 结构 | 拆分 `SessionWorkspace` 为配置条／数字人区／对话区等小组件；补前端单测 |
| 文档 | 更新 README、项目状态、本阶段证据包 |

### 本阶段不做

- 上线、域名、登录／邀请码  
- 真数字人视频／RTC  
- 多入口运营台、RAG、管理后台独立站  
- 改 D2／D3 标准；改后端 FAQ／Agent 逻辑  

## 三、通过条件（闸门）

1. guest 默认进入后，页面上**找不到**「打开／关闭 Agent」与特殊指令行（除非进入 lab）  
2. guest：开始咨询 → 发一句 → 看到回复；可转人工（需确认）／评价  
3. lab：仍能完成第 1 阶段全套验收路径（含降级模拟）  
4. 前端 vitest 通过；`tsc` + `next build` 通过；后端 pytest 回归通过  
5. 密钥仍不进前端；README／状态／证据包已更新  

## 四、交互与状态

### 4.1 模式

```text
默认 guest
  └─ 点击「验收模式」→ lab（角标可见）
       └─ 「返回访客」→ guest
```

- `sessionStorage.key = dh_ui_mode`，值 `guest`｜`lab`  
- lab 下可改 Agent；guest **只读展示**「智能助手已启用／未启用」（来自 config），不可切换。

### 4.2 访客主路径

```text
开始咨询
  → POST /sessions
  → POST /guide
  → POST /digital-human/init { d_profile_key }
  → 可发消息
发消息成功
  → 刷新 history
  → 自动 push（失败则横幅提示，不阻断已展示的口播）
降级
  → 仅友好文案横幅（由 lab 触发模拟，或后续真机超时）；guest 无「模拟降级」按钮
转人工
  → 确认 → POST /transfer → 禁用输入
```

### 4.3 视觉

延续第 1 阶段青绿＋对话布局；guest 更干净（少按钮）。换肤仍可用。

## 七、验收清单（产品经理）

**访客模式**

1. 打开 3050，默认看不到 Agent 开关、特殊指令  
2. 点「开始咨询」，能直接聊天  
3. 发「怎么退货？」，有口播气泡  
4. 点转人工 → 取消则仍可聊；确认后不能再发  
5. 评价仍可用  

**验收模式**

6. 进入 lab，打开／关闭 Agent 各试一句  
7. 手动推流 → 开始展示 → 模拟降级出现黄条  

**窄屏**

8. 约手机宽度再走访客主路径一遍  

## 八、风险与默认

| 点 | 默认 |
| --- | --- |
| 自动 push 与打断规则 | guest 只 auto-push，不 auto-started，避免事件挡 NLP |
| Agent 对 C 端 | 不开放开关；是否启用由服务端 config 决定 |
| 与 8050 联调页 | 仍保留；演示优先 3050 |
