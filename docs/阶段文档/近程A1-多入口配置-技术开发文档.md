## 一、目标（产品语言）

本地可以有两个「窗口」：

1. **通用金融咨询**（默认）  
2. **信用卡专窗**  

验收的人能在验收模式里切换入口再开咨询；客户用的访客壳**看不到**入口选择，也**看不到** Agent 总闸，只会走默认入口。

## 四、接口与数据（摘要）

### `GET /api/v1/config`

在原有字段上增加：

```json
{
  "pilot_entry_id": "entry_pilot_001",
  "agent_enabled": false,
  "entries": [
    {
      "id": "entry_pilot_001",
      "label": "通用金融咨询",
      "welcome_text": "…",
      "theme": "default",
      "accent": "#0f766e",
      "logo_url": "",
      "agent_enabled": false
    },
    {
      "id": "entry_credit_001",
      "label": "信用卡专窗",
      "welcome_text": "…",
      "theme": "ink",
      "accent": "#0e7490",
      "logo_url": "",
      "agent_enabled": true
    }
  ]
}
```

说明：`entries[].theme / accent / logo_url / agent_enabled` **本阶段先随配置下发**，供 A2 使用；A1 建会话只校验 `id` 是否在白名单。

### `POST /api/v1/sessions`

- 请求：`{ "entry_id": "entry_credit_001" }`  
- 成功：返回该 `entry_id`  
- 失败：不在白名单 → `403`，`error.code = ENTRY_NOT_ALLOWED`

### `PUT /api/v1/config`（验收／联调）

- 可传 `agent_enabled`（全局总闸）和／或 `pilot_entry_id`（访客默认入口）  
- 字段均可选；改 `pilot_entry_id` 时必须在白名单内

## 六、产品经理验收（照着点）

1. 打开 http://127.0.0.1:3050/ ，**强制刷新**（`Cmd + Shift + R`）  
2. **访客模式**  
   - 页面上**没有**「本地入口」下拉  
   - 页面上**没有**「打开／关闭总闸 Agent」  
   - 点「开始咨询」能出欢迎语并正常聊天  
3. 右上角切到 **验收模式**  
   - 能看到「本地入口」：通用金融咨询／信用卡专窗  
   - 能看到「打开／关闭总闸 Agent」（这是给你们测的，不是给客户的）  
4. 选「信用卡专窗」→ 点「创建会话」  
   - 顶栏说明里应出现「信用卡专窗」字样  
5. （可选）用错误入口调接口应被拒绝——开发已用自动化覆盖，产品经理可不测
