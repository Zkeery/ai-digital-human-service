# 前端第 5 阶段 · 开场快捷入口 · 技术开发文档

> **线路：前端。**  
> 承接第 4 阶段快捷按钮。不上线。不改后端契约（点选仍走现有发消息）。

## 一、目标（产品话）

开始咨询后，还没进入退货／退款多轮时，输入框上方先给出常用入口，少打字：

- 怎么退货？  
- 退款  
- 营业时间  

点了就当用户发了那句话；一旦后端返回流程内 `quick_replies`，仍优先显示后端选项。

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 开场芯片 | 会话 active、未结束、且当前无后端 `quick_replies` 时展示 |
| 点击 | 复用现有 `onSend(text)` |
| 隐藏 | 转人工结束、或后端已下发流程选项时隐藏开场项 |
| 单测 | 何时展示开场芯片的纯函数 |

### 不做

- 改后端 FAQ／状态机  
- 上线、登录、真数字人  

## 三、通过条件

1. 开始咨询后（可先有欢迎气泡）可见开场三按钮  
2. 点「怎么退货？」→ 进入退货探因，开场按钮换成后端探因选项  
3. 点「退款」→ 进入退款澄清选项  
4. vitest／typecheck／build 通过  

## 四、验收清单（3050）

1. 开始咨询 → 看到「怎么退货？／退款／营业时间」  
2. 点「怎么退货？」→ 出现尺码等探因按钮  
3. 新开一轮点「退款」→ 出现澄清按钮  

## 五、完成定义

手测通过后完成。
