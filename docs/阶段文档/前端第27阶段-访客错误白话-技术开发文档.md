# 前端第 27 阶段 · 访客错误白话 · 技术开发文档

## 一、目标

访客看到的失败提示是人话：不带技术错误码；网络不通、会话已结束等有固定白话。

## 二、范围

1. `formatApiError(err, { audience: "guest" | "lab" })`  
2. 访客：映射常见码／网络失败；不展示 `（CODE）`  
3. 联调模式：仍带错误码，便于排查  
4. SessionWorkspace 按当前模式选择 audience  

## 三、不做

- 多语言  
- 上线  

## 四、验收

1. 访客模式：转人工后再发消息（或等价触发会话不可用）→ 红条是白话，**无** `SESSION_NOT_ACTIVE` 一类码  
2. 断网／停后端后发消息 → 类似「暂时连不上客服…」  
3. 联调模式仍可见错误码  
4. vitest 通过
