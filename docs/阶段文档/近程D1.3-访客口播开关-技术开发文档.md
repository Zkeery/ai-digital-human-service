# 近程 D1.3 · 访客口播开关 · 技术开发文档

> 承接 D1／D1.1。仍不上线、不接真 RTC；费用 **¥0**。

## 1. 目标

访客不必进验收模式，也能一键开关本地口播（静音／恢复）。

## 2. 范围

| 做 | 不做 |
| --- | --- |
| 访客顶栏「口播：开／关」按钮 | 改默认策略（仍默认开） |
| 沿用 `dh_local_speech` 本地存储与 D1 朗读逻辑 | 系统级音量、云 TTS |
| 验收模式原有打开／关闭本地口播保留 | 真 RTC |

## 3. 验收（照着点）

1. http://127.0.0.1:3050/ 强制刷新（访客模式）  
2. 顶栏可见「口播：开」  
3. 点成「口播：关」→ 开始咨询／发「查余额」→ **不朗读**  
4. 再点回「口播：开」→ 再发一句 → **能朗读**  
5. 强制刷新后开关状态保持
