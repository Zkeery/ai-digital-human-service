## 一、目标（产品语言）

在验收模式里能一眼看到本机演示数据：

1. 一共开过多少会话、多少还在进行、多少已转人工  
2. Agent 用了几次、跳过几次  
3. **按入口**拆开：通用／信用卡各自多少会话、转人工、Agent  

不做独立运营后台，不导出，不接现网大盘。访客模式**看不到**这块。

## 四、接口摘要

### `GET /api/v1/stats`

```json
{
  "sessions_total": 2,
  "sessions_active": 1,
  "sessions_transferred": 1,
  "transfer_events": 1,
  "agent_used": 1,
  "agent_skipped": 1,
  "messages_replied": 2,
  "ratings": 0,
  "by_entry": [
    {
      "entry_id": "entry_pilot_001",
      "label": "通用金融咨询",
      "sessions": 1,
      "transferred": 0,
      "agent_used": 0,
      "agent_skipped": 1
    }
  ]
}
```

说明：`sessions_transferred` 看会话状态；`transfer_events` 看 `dh_transfer_human` 事件次数。白名单入口即使零会话也会出现在 `by_entry`。

## 六、产品经理验收（照着点）

1. http://127.0.0.1:3050/ 强制刷新  
2. **访客模式**：页面上**没有**「本地统计（验收）」  
3. 切 **验收模式**：右侧／下方应出现「本地统计（验收）」  
4. 选不同入口各创建一次会话，发一句、其中一条走「转人工」  
5. 创建会话／发消息／转人工后统计应**自动更新**（也可点「刷新统计」）；通用与信用卡两行都会变；通用入口 Agent 默认计为跳过
