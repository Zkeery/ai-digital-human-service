# 前端第 10 阶段 · 开场加取消订单 · 技术开发文档

> **线路：前端。**  
> 承接后端第 11 阶段取消订单咨询（含已发货挽留）。只改开场快捷入口。不上线。

## 一、目标（产品话）

开场增加 **取消订单**：一点就发「取消订单」，进入后端取消澄清；若选「已经发货」应先听到挽留，而不是直接教拒收／退货。

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 开场芯片 | `STARTER_QUICK_REPLIES` 增加「取消订单」 |
| 点击 | 复用现有 `onSend("取消订单")` |
| 单测 | 断言开场列表含「取消订单」 |
| 关键文件 | `frontend/features/session/quickReplies.ts` · `frontend/tests/quick-replies.test.ts` |

### 不做

- 改后端取消／挽留状态机（属后端第 11）  
- 真取消接口、上线  

## 三、通过条件

1. 开始咨询可见「取消订单」  
2. 点后出现「还没发货／已经发货」澄清按钮  
3. 「已经发货」→ 挽留选项含「还是要取消／先等等看」  
4. vitest／typecheck／build 通过  

## 四、验收清单（3050）

1. 开始咨询 → 看到「取消订单」  
2. 点「取消订单」→「已经发货」→ 先挽留  
3. 可选再点「还是要取消」→ 才听到拒收／退货说明  

## 五、完成定义

手测通过后完成。证据见 `docs/evidence/前端第10阶段/`。
