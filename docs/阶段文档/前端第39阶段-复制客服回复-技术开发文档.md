# 前端第 39 阶段 · 复制客服回复 · 技术开发文档

## 一、目标

访客可一键复制最近一条客服回复，方便对照官方 App／网点操作，无需长按选中。

## 二、范围

| 改 | 不改 |
| --- | --- |
| `latestAssistantText`／复制按钮文案 | 后端、API |
| `copyTextToClipboard` 与 ChatPanel 按钮 | 导出整段会话 |
| | 上线／多入口 |

## 三、验收

1. 3050 开始咨询并发「查余额」  
2. 客服回复出现后，见「复制回复」  
3. 点击后按钮变为「已复制」，粘贴可见刚才那段回复  
4. `npm test` 全过
