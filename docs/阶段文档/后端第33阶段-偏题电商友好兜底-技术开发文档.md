# 后端第 33 阶段 · 偏题／电商友好兜底 · 技术开发文档

## 一、目标

用户说网购售后或完全不相干的问题时，不再落到干巴巴的通用失败句，也不走进历史电商多轮；明确「本客服做零售金融」，并给可问示例。

## 二、范围

- `faq.match_ecommerce_offtopic`／`match_aside`／友好 `default_fallback_reply`
- 寒暄 FAQ 与访客欢迎语对齐（零售金融）  
- `sessions` 未命中金融多轮时走 aside → Agent（若开）→ 兜底  

不改金融多轮正文；不接真电商系统。

## 三、验收

1. 「怎么退货／查物流／优惠券」→ 明示不办网购售后，引导金融问题；`source=offtopic_rule`  
2. 「今天天气怎么样」→ 友好兜底，带「查余额」等示例  
3. 「你好」→ 零售金融寒暄  
4. pytest 通过
