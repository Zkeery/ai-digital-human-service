# 前端第 12 阶段 · 开场加投诉 · 技术开发文档

> **线路：前端。**  
> 承接后端第 13 阶段投诉引导。只改开场快捷入口。不上线。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。

## 一、目标（产品话）

开场增加 **我要投诉**（替换原「营业时间」占位，因开场最多 8 个）。  
一点就发「我要投诉」，进入投诉类型澄清。营业时间仍可手打，FAQ 仍在。

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 开场芯片 | `STARTER_QUICK_REPLIES`：去掉「营业时间」，增加「我要投诉」 |
| 点击 | 复用 `onSend("我要投诉")` |
| 单测 | 断言含「我要投诉」、不含「营业时间」 |
| 关键文件 | `frontend/features/session/quickReplies.ts` · `frontend/tests/quick-replies.test.ts` |

### 不做

- 改后端投诉状态机  
- 真工单、自动转接  

## 三、通过条件

1. 开始咨询可见「我要投诉」，不见「营业时间」开场钮  
2. 点后出现物流／商品／服务态度等澄清按钮  
3. vitest／typecheck／build 通过  

## 四、验收清单（3050）

1. 开始咨询 → 看到「我要投诉」  
2. 点「我要投诉」→ 出现类型选项  
3. 点「物流问题」→ 听到安抚与转人工建议  

## 五、完成定义

手测通过后完成。证据见 `docs/evidence/前端第12阶段/`。
