# 后端第 27 阶段 · 网点／营业时间 · 技术开发文档

> **线路：后端。** 不上线、**不查真网点库存／实时排队、不承诺具体开门时刻**。  
> 开场不铺入口；用户说到网点／营业时间等进入。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。  
> 业务线：零售金融客服（PRD V0.3）。

## 一、目标（产品话）

用户问网点或时间相关时，先短问一句，再分流：

1. **怎么查网点** → App「网点查询」路径  
2. **网点营业时间** → 以 App／网点页披露为准；本客服不承诺具体时刻  
3. **客服在线时间** → 说明以 App／官方公布的在线客服时间为准  
4. 答完一项后追问其余项，选项保留（同第26）

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 状态 | `branch_flow`：`idle`／`awaiting_clarify`；`branch_seen` 记录已答项 |
| 触发 | 网点、营业时间、几点开门、客服时间 等 |
| 分支 | 怎么查网点／网点营业时间／客服在线时间／转人工 |
| 关键文件 | `branch_dialogue.py` · `sessions.py` · 状态 pack · `test_stage27_branch.py` |

### 不做

- 实时查某网点是否开门、代预约、承诺具体时刻  

## 三、状态机

```text
idle → 问网点／时间相关 → awaiting_clarify
  ├─ 怎么查网点 → 短指引＋追问 → 仍 awaiting_clarify
  ├─ 网点营业时间 → 短说明＋追问 → 仍 awaiting_clarify
  ├─ 客服在线时间 → 短说明＋追问 → 仍 awaiting_clarify
  ├─ 三项都问过 → 收口 → idle
  ├─ 不用了／没有了 → 收口 → idle
  └─ 转人工 → 建议转人工 → idle
```

## 话术原则

- **准确**：路径与边界清楚；禁用「多半／一般／大概」  
- 时间以 App／官方披露为准，不口头承诺具体时刻  
- **追问**：答完一项后追问其余标签；选项不立刻清空  

## 四、通过条件

1. 「网点」／「营业时间」→ 澄清或分支答 + 选项≤5  
2. 点完一项后选项仍在且有「您还想咨询…」  
3. 与既有金融多轮互不抢  
4. pytest 通过（含准确度门禁）  

## 五、验收（3050／8050）

手打「网点」→ 点「怎么查网点」→ 确认追问与选项 → 再点一项。
