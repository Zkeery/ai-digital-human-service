# 后端第 19 阶段 · 咨询话术口语化 · 技术开发文档

> **线路：后端。** 不改状态机与开场入口，只改口播文案。不上线。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。

## 一、目标（产品话）

流程已能跑通，但口播偏说明书腔。本阶段把各咨询场景的澄清句与分支答，写成更像真人客服随口说的短句。

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 文案 | 各 `*_dialogue.py` 的 clarify／分支／转人工口播 |
| 原则 | 短、自然、可执行；少「即可／请点击／关于X：」套话；不复读选项名 |
| 测试 | 断言改为语义锚点，不锁死旧长句 |
| 手册 | 总览话术约定补强 |

### 不做

- 新开场景、改状态字段、接真系统、改前端开场结构  

## 三、通过条件

1. 澄清句不再共用「您具体遇到了什么…问题？」长模板  
2. 分支答口语化，pytest 全绿  
3. 3050 抽 2～3 条场景听感明显更自然  

## 四、验收（3050）

任选：价保、支付问题、优惠券 — 走一轮，听口播是否像人说话。

## 五、完成定义

手测认可后完成。证据见 `docs/evidence/后端阶段19-话术口语化/`。
