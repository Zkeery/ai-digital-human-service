# 前端第 18 阶段 · 开场入口收纳 · 技术开发文档

> **线路：前端。** 不上线。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。

## 一、目标（产品话）

开场快捷入口已有 13 个，一屏太挤。本阶段把高频放主排，低频收到「更多」里，点开再选。

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 主排 | 怎么退货？· 换货 · 退款 · 取消订单 · 查物流 · 支付问题 · 我要投诉 |
| 更多 | 开发票 · 改地址 · 优惠券 · 保修 · 会员积分 · 价保 |
| 交互 | 开场时主排可见；点「更多」展开／收起次排 |
| 流程选项 | 后端下发的流程芯片仍一次全展示（不套「更多」） |
| 单测 | 主排／更多分组正确 |
| 关键文件 | `quickReplies.ts` · `ChatPanel.tsx` · `globals.css` · 测试 |

### 不做

- 改后端状态机、删场景、上线  

## 三、通过条件

1. 开始咨询后主排约 7 个，可见「更多」  
2. 点「更多」出现价保等次排入口  
3. 进入流程后选项仍正常（不套「更多」）  
4. vitest 通过  

## 四、验收（3050）

1. 开始咨询 → 主排不挤、有「更多」  
2. 点「更多」→ 见「价保」并点进路径  

## 五、完成定义

手测通过后完成。证据见 `docs/evidence/前端第18阶段/`。
