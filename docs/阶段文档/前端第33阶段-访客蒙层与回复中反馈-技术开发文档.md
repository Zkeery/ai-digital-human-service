# 前端第 33 阶段 · 访客蒙层与回复中反馈 · 技术开发文档

## 一、目标

按《产品设计文档》C 端信息架构与《设计走查清单》#6，只改前端界面：

1. 访客态更接近「数字人主视觉 + 对话叠层」蒙层客服壳  
2. 回复／播报中输入区有更清晰的锁定反馈（仍不放开打断发送）  
3. 验收模式（lab）布局与控件保持原样；**不改 API、不改会话状态机、不接真 RTC**

## 二、范围

| 改 | 不改 |
| --- | --- |
| `guestView`：壳 class、锁定／角标／占位与提示（含 statusCue） | 后端接口与推流契约 |
| `SessionWorkspace`／`ConfigBar`／`AvatarPanel`／`ChatPanel` 访客呈现 | 转人工／评价／Agent 逻辑 |
| `globals.css`：`guest-shell`、角标、`composer.is-locked` | 一期真换肤运营配置、多入口 |

## 三、验收

1. 打开 http://127.0.0.1:3050/ 访客模式：顶栏紧凑；数字人区与对话区呈蒙层叠层（桌面左右分栏）  
2. 点「开始咨询」→ 发「查余额」：数字人角标见「回复播报中」；对话有「正在回复…」；输入区高亮锁定且提示「发送已暂缓」  
3. 回复出来后角标／锁定消失，可继续发  
4. 切「验收模式」：仍见形象选择、推流等验收控件，布局不套 guest-shell  
5. `npm test` 全过；`npm run build` 通过
