# 前端第 23 阶段 · 刷新恢复会话 · 技术开发文档

## 一、目标

浏览器刷新后，仍能回到本标签页上一轮咨询：历史气泡、会话状态（进行中／已转人工）不丢。

## 二、范围

1. 后端：`GET /api/v1/sessions/{session_id}` 返回 `session_id`／`entry_id`／`status`  
2. 前端：本标签 `sessionStorage` 记住会话 id；进入页时拉取状态与历史  
3. 会话不存在则清本地记忆，回到未开始态；「重新开始咨询」覆盖为新会话  

## 三、不做

- 跨设备／跨浏览器恢复  
- 刷新后自动恢复快捷标签（需再问一句）  
- 上线部署  

## 四、验收

1. 开始咨询并说「查余额」→ 强制刷新 → 气泡仍在，可继续发  
2. 转人工后刷新 → 仍见结束卡片与「重新开始咨询」  
3. 清掉后端会话或伪造 id 后刷新 → 不卡死，可重新开始  
4. 自动化测试通过
