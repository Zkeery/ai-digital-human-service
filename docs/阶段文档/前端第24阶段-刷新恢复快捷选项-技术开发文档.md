# 前端第 24 阶段 · 刷新后恢复快捷选项 · 技术开发文档

## 一、目标

刷新恢复会话后，若多轮澄清尚未答完，快捷选项仍在，不必重打第一句。

## 二、范围

1. `GET /sessions/{id}` 在 `active` 时附带 `last_reply`（含按当前对话状态重算的 `quick_replies`）  
2. 前端恢复会话时写入 `lastReply`，聊天区重新展示 chips  
3. 已转人工／无多轮态：不强制出 chips  

## 三、不做

- 恢复口播推流指令 id  
- 跨标签／跨设备  
- 上线  

## 四、验收

1. 「查余额」出现选项 → 刷新 → 选项仍在，可点  
2. 答完某项后刷新 → 已答项仍隐藏（与第 32 一致）  
3. 转人工后刷新 → 无输入区 chips  
4. 自动化通过
