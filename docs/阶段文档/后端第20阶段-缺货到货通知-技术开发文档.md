# 后端第 20 阶段 · 缺货／到货通知 · 技术开发文档

> **线路：后端。** 不上线、不查真库存、不接订阅系统。  
> 开场不铺入口；用户说到缺货／到货通知等关键词进入。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。

## 一、目标（产品话）

用户问缺货或到货通知时，先短问一句，再分流：

1. **什么时候有货** → 怎么看预计到货  
2. **订到货通知** → 自助订阅短指引  
3. **订了没通知** → 留证、转人工  
4. 可点快捷选项（≤5）

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 状态 | `stock_flow`：`idle`／`awaiting_clarify` |
| 触发 | 缺货、没货、到货通知、什么时候有货、补货 等 |
| 分支 | 什么时候有货／订到货通知／订了没通知／转人工 |
| 关键文件 | `stock_dialogue.py` · `sessions.py` · 各对话 pack · `test_stage20_stock.py` |

### 不做

- 真改库存、真发短信／推送订阅  

## 三、状态机

```text
idle → 问缺货／到货通知 → awaiting_clarify
  ├─ 什么时候有货 → 短指引 → idle
  ├─ 订到货通知 → 短指引 → idle
  ├─ 订了没通知 → 短指引＋转人工 → idle
  └─ 转人工 → 建议转人工 → idle
```

## 话术原则

- 澄清一句口语；分支短答，不复读选项名  

## 四、通过条件

1. 「缺货」／「到货通知」→ 短澄清 + 选项  
2. 「订了没通知」→ suggest 转人工  
3. pytest 全绿  

## 五、验收（3050）

手打「到货通知」走完路径。
