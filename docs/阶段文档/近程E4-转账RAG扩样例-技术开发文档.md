# 近程 E4 · 转账 RAG 扩样例 · 技术开发文档

> 承接 E3：为转账怎么转／失败／未到账／到账时间挂公开样例依据。  
> **不上线**。不代客转账、不承诺到账时刻。

## 一、目标（产品语言）

打开 RAG 后：

1. 「怎么转账」「转账失败」能挂样例依据  
2. 「多久能到」清楚说不能承诺具体到账时间  
3. 关 RAG 时仍只走原转账规则话术  

## 二、范围

| 改 | 不改 |
| --- | --- |
| 转账 4 条公开样例＋门禁 H7／H8／R5 | 真核心到账查询／代客转账 |
| topic／graphic | Embedding／上线 |

## 三、门禁摘要

| 编号 | 问法 | 必须 |
| --- | --- | --- |
| H7 | 怎么转账 | `transfer_howto_sample_001`＋样例依据 |

| R5 | 多久能到能不能保证今天到 | 命中到账时间样例；禁「保证今天到」 |

## 四、产品经理验收（照着点）

1. **重启后端**后 http://127.0.0.1:3050/ → 打开 RAG  
2. 问「怎么转账」→ 有样例依据  
3. 问「转账失败」→ 有排查样例依据  
4. 问「多久能到能不能保证今天到」→ 不承诺今天到  
5. 关 RAG 后再问「转账失败」→ 无样例依据
