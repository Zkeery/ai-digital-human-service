# 近程 D1.1 · 开场欢迎口播 · 技术开发文档

> 承接 D1。仍不上线、不接真 RTC；费用 **¥0**。

## 1. 目标

点「开始咨询」后，不只出现欢迎文字，还能**听见欢迎口语播报**（本地口播关着则只出字）。

## 2. 范围

| 做 | 不做 |
| --- | --- |
| 访客开始咨询 → init Room → **本地朗读欢迎语**（欢迎指令保持 queued，避免挡住后续应答推流） | 真 RTC；不对欢迎语 mark stream-started |
| 连带发送示例问题时跳过欢迎朗读（避免被下一条立刻打断） | 改欢迎语文案／入口策略 |
| 沿用 D1 开关与埋点 `dh_local_speech` | 云 TTS |

## 3. 验收（照着点）

1. http://127.0.0.1:3050/ 强制刷新  
2. 访客点「开始咨询」（先别点示例问题）  
   - [ ] 对话区出现欢迎语  
   - [ ] 数字人出现「本地口播中」  
   - [ ] 能听见欢迎语朗读  
3. 再点「查余额」示例 → 仍能听到应答口播  
4. 验收模式关闭本地口播 → 再开始咨询 → 无朗读
