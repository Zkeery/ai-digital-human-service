# 前端第 31 阶段 · 深色换肤可读 · 技术开发文档

## 一、目标

切到「深色」后，客服气泡、空状态、结束卡片仍清晰；顶栏「转人工」滚动时更易看见。

## 二、范围

- `globals.css`：浅色下客服气泡略加强边界；`theme-ink` 下 assistant／welcome／pending／ended-card／ghost 按钮
- 数字人区 DH／字幕、访客提示条、回复状态条对比度加强
- 对话工具栏 sticky 阴影（浅／深两套）
- `ChatPanel`：新消息／回复中占位时自动滚到底
- 访客下拉文案：「界面风格 · 浅色／深色」

## 三、验收

1. 3050 访客 → 界面风格选「深色」→ 聊几句，客服与用户气泡仍可分
2. 长对话向下滚，顶栏「转人工」仍带阴影浮在对话上
3. 发一句、客服回一句后，对话区自动滚到最新，无需手拖滚动条
4. 顶部提示条、数字人底部字幕清晰可读
5. vitest 全过
