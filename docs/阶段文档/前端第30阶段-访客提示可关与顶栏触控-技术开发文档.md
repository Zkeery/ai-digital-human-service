## 一、目标

访客首屏有简短操作说明，点「知道了」后**本轮咨询**不再出现；顶栏「验收模式／换肤」更好点（≥44px）。

1. `GuestTipBanner` + `guestView` 按 `sessionId` 记 dismiss（`sessionStorage`）
2. 转人工后不再展示提示
3. `ModeSwitch`、换肤下拉去掉过小按钮，统一触控高度
4. 深色换肤下提示条对比可读；减弱动效时 busy 呼吸动画关闭

1. 打开 3050 访客模式 → 标题下见提示条 → 点「知道了」消失
2. 同一会话刷新仍不出现；点「重新开始咨询」开新会话后再出现
3. 「验收模式」「换肤」高度 ≥44px
4. vitest 通过
