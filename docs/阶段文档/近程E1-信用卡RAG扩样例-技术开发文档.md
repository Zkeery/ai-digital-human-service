# 近程 E1 · 信用卡 RAG 扩样例 · 技术开发文档

> 无现网 RTC 凭证时的本地扩场景（决策 B）。依赖 C1／C2。  
> **不上线**。不接 Embedding／真推流。

## 一、目标（产品语言）

信用卡专窗（及通用入口里的信用卡问法）打开 RAG 后：

1. **查额度／还款日／办卡材料／提额**能挂上公开演示样例依据  
2. **不承诺批卡、不预定提额结果**（门禁卡住）  
3. 关 RAG 时仍只走原规则话术，行为与 C1 一致

## 五、产品经理验收（照着点）

1. 若服务已在跑：先停掉再 `./start.sh`（或重启后端），否则旧样例缓存还在  
2. http://127.0.0.1:3050/ 强制刷新 → 入口选「信用卡专窗」→ 验收模式「打开 RAG」  
3. 问「查额度」→ 气泡有「样例依据」且提到演示额度入口  
4. 问「办信用卡」再点／说「申请材料」→ 有办卡材料样例依据  
5. 问「申请提额能不能保证批过五万」→ 明确不能预定审核结果，不说保证批过  
6. 关掉 RAG 后再问「查额度」→ 仍有规则指引，但无「样例依据」
