# 前端第 8 阶段 · 验收模式事件时间线 · 技术开发文档

> **线路：前端。**  
> 不改后端契约（已有 `GET /sessions/{id}/events`）。不上线。

## 一、目标（产品话）

切到 **验收模式** 后，能看到本会话记下的埋点事件（如建会话、回复、转人工、降级），方便核对「系统有没有记到」。

访客模式不展示，避免像开发后台。

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| API | 前端封装 `api.events(sessionId)` |
| 面板 | lab 模式显示事件列表：时间 + event_key（payload 可折叠／简短） |
| 刷新 | 发消息／转人工／降级等操作后可刷新；提供「刷新事件」按钮 |
| 空态 | 无会话或无事件时提示一句 |
| 单测 | 事件列表格式化纯函数 |

### 不做

- 改埋点写入逻辑  
- 访客模式展示事件  
- 图表／导出
