## 一、目标（产品语言）

口播时数字人画面更像「在说话」：

1. **待机**：立绘轻微上下浮动  
2. **本地口播中**：立绘轻晃 + 底部声浪条 + 字幕预览（截断应答文案）  
3. **系统偏好减少动态**：动效关闭，仍保留角标与字幕

## 四、产品经理验收（照着点）

1. http://127.0.0.1:3050/ 强制刷新  
2. 开始咨询 → 发「查余额」（口播开关打开）  
3. 口播期间应看到：黄角标「本地口播中」、立绘轻晃、底部黄色声浪、底部字幕有应答摘要  
4. 点「跳过口播」或播完 → 声浪与字幕消失，立绘回到轻浮动  
5. 关闭「本地口播」再发一句 → 无声浪／无口播字幕预览
