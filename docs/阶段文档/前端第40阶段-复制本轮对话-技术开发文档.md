# 前端第 40 阶段 · 复制本轮对话 · 技术开发文档

## 一、目标

在「复制回复」之外，支持一键复制本轮完整对话（欢迎／我／客服），方便留存或发给人工协助。

## 二、范围

| 改 | 不改 |
| --- | --- |
| `formatTranscript`／「复制本轮对话」按钮 | 后端、API、文件下载 |
| ChatPanel 双按钮并列 | 上线／多入口 |

## 三、验收

1. 3050 开始咨询 → 发「查余额」  
2. 见「复制回复」与「复制本轮对话」  
3. 点「复制本轮对话」→「对话已复制」  
4. 粘贴应含欢迎语、自己的话、客服回复  
5. `npm test` 全过
