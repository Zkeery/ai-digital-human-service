# 近程 D1.4 · 口播可跳过 · 技术开发文档

> 承接 D1～D1.3。仍不上线、不接真 RTC；费用 **¥0**。

## 1. 目标

本地口播进行中时，可点「跳过口播」立刻停止朗读，不必等说完。

## 2. 范围

| 做 | 不做 |
| --- | --- |
| 口播中（`speaking`）在**页顶状态条**显示「跳过口播」（只保留这一处） | 打断正在发送的网络请求；数字人区不再重复放按钮 |
| 跳过 = 取消 `speechSynthesis` + 清角标 | 改欢迎语／应答文本 |
| 埋点 `dh_local_speech` detail=`skip` | 真 RTC |

## 3. 验收（照着点）

1. http://127.0.0.1:3050/ 强制刷新，口播保持开  
2. 点「开始咨询」→ 出现「本地口播中」与「跳过口播」  
3. 点「跳过口播」→ 朗读立刻停，角标消失  
4. 再发「查余额」→ 仍可正常口播
