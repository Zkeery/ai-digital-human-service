## 1. 目标（产品语言）

访客问完后，数字人区域不只闪「回复播报中」，还能**听得见口播**（浏览器本地语音），并标明这是本地预览、不是现网直播。

## 2. 范围

| 做 | 不做 |

## 4. 实现要点

1. 前端模块 `localSpeech.ts`：可取消、截断过长文本、优先中文音色；无能力时静默跳过。  
2. 访客发送成功 → `push` → `streamStarted` → 启动本地口播。  
3. 口播期间 `statusCue=speaking`：角标可见，**不锁输入**（文字已出齐）。  
4. 验收顶栏可开关；键名 `dh_local_speech`（默认开）。  
5. 埋点：`dh_local_speech`（detail：`start`／`end`／`unsupported`／`error`）。

## 5. 验收（照着点）

1. http://127.0.0.1:3050/ 强制刷新（`Cmd + Shift + R`）  
2. 访客：开始咨询 → 发「查余额」  
   - [ ] 文字回复出现  
   - [ ] 数字人角标出现「本地口播中」（或短暂「回复播报中」后接上）  
   - [ ] 本机能听到中文朗读（系统未禁音／浏览器允许）  
3. 验收模式：关闭「本地口播」后再发一句 → 不再朗读  
4. 验收模式事件／埋点可见 `dh_stream_started` 或本地 `dh_local_speech`
