# 后端第 26 阶段 · 理财说明书解读 · 技术开发文档

> **线路：后端。** 不上线、**不荐股、不承诺收益、不代客购买／赎回**。  
> 开场不铺入口；用户说到理财／说明书／风险等级等进入。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。  
> 业务线：零售金融客服（PRD V0.3）。

## 一、目标（产品话）

用户问理财产品相关时，先短问一句，再分流：

1. **在哪看说明书** → 自助入口短指引（只指已公开材料）  
2. **风险等级怎么看** → 说明以说明书披露为准，不替用户做适合度结论  
3. **收益怎么理解** → 说明历史／测算表述不等于承诺收益；细节以说明书为准  
4. 可点快捷选项（≤5）

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 状态 | `wealth_flow`：`idle`／`awaiting_clarify`；`wealth_seen` 记录已答项 |
| 触发 | 理财、说明书、产品说明书、风险等级、理财收益 等 |
| 分支 | 在哪看说明书／风险等级怎么看／收益怎么理解／转人工 |
| 关键文件 | `wealth_dialogue.py` · `sessions.py` · 状态 pack · `test_stage26_wealth.py` |

### 不做

- 荐股／荐品、收益承诺、代客申购／赎回、解读未公开材料  

## 三、状态机

```text
idle → 问理财／说明书相关 → awaiting_clarify
  ├─ 在哪看说明书 → 短指引＋追问其余项 → 仍 awaiting_clarify（选项保留）
  ├─ 风险等级怎么看 → 同上
  ├─ 收益怎么理解 → 同上
  ├─ 三项都问过 → 收口说明 → idle
  ├─ 不用了／没有了 → 收口 → idle
  └─ 转人工 → 建议转人工 → idle
```

## 话术原则

- **准确**：菜单路径与能力边界说清楚；禁用「多半／一般／大概／我保证不了」  
- **只解读已公开材料**：引导用户打开产品页／说明书；不编造条款  
- 不承诺收益；不替用户判断「适不适合买」  
- **追问**：答完一项后追问是否还要咨询其余标签；选项不立刻清空  

## 四、通过条件

1. 「理财」／「说明书」→ 澄清或分支答 + 选项≤5  
2. 「收益怎么理解」→ 明确不等于承诺收益  
3. 点完一项后快捷选项仍在，且口播有「您还想咨询…」追问  
4. 与既有金融多轮互不抢  
5. pytest 通过（含准确度门禁）  

## 五、验收（3050／8050）

手打「理财」→ 点「在哪看说明书」→ 确认仍有其他选项且口播追问 → 再点「收益怎么理解」。
