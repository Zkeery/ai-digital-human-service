# 前端第 7 阶段 · 开场加开发票 · 技术开发文档

> **线路：前端。**  
> 承接后端第 9 阶段发票开票咨询。只改开场快捷入口。不上线。

## 一、目标（产品话）

开场增加 **开发票**：一点就发「开发票」，进入后端发票澄清（电子／纸质／重开改抬头），少打字。

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 开场芯片 | `STARTER_QUICK_REPLIES` 增加「开发票」 |
| 点击 | 复用现有 `onSend("开发票")` |
| 单测 | 断言开场列表含「开发票」 |
| 关键文件 | `frontend/features/session/quickReplies.ts` · `frontend/tests/quick-replies.test.ts` |

### 不做

- 改后端发票状态机  
- 真开票接口、登录、上线  

## 三、通过条件

1. 开始咨询可见「开发票」  
2. 点后出现电子／纸质／重开改抬头等澄清按钮  
3. vitest／typecheck／build 通过  

## 四、验收清单（3050）

1. 开始咨询 → 看到「开发票」  
2. 点「开发票」→ 出现发票类型选项  
3. 点「电子发票」→ 听到电子票办理说明  

## 五、完成定义

手测通过后完成。证据见 `docs/evidence/前端第7阶段/`。
