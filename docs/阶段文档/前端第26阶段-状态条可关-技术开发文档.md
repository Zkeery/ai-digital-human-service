# 前端第 26 阶段 · 状态条可关与成功自动消失 · 技术开发文档

## 一、目标

顶栏状态条不再长期挡对话：成功提示短时自动消失；错误／警告可手动关闭；访客发消息不再每次弹出「发送成功」。

## 二、范围

1. 状态条统一组件：文案＋关闭  
2. `ok` 约 3 秒自动消失；`warn` 约 8 秒；`err` 不自动关  
3. 访客模式：发送／开始咨询成功不弹绿条（失败仍提示）  
4. `prefers-reduced-motion`：减弱数字人呼吸动效  

## 三、不做

- 完整 toast 队列／多条堆叠  
- 上线  

## 四、验收

1. 访客发一句「查余额」：无「发送成功」绿条挡屏；对话正常  
2. 人为断后端或触发错误：红条出现，点关闭可去掉  
3. 刷新恢复：绿条「已恢复…」约数秒后自行消失  
4. 系统「减少动态效果」开启时，数字人光晕不再呼吸动画
