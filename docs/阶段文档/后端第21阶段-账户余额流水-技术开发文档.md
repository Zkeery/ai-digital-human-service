# 后端第 21 阶段 · 账户／余额／流水指引 · 技术开发文档

> **线路：后端。** 不上线、**不查真账**。  
> 开场不铺入口；用户说到查余额／流水／账户等关键词进入。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。  
> 业务线：零售金融客服（PRD V0.3）。

## 一、目标（产品话）

用户问怎么查账户、余额或流水时，先短问一句，再分流：

1. **查余额** → 自助入口短指引  
2. **查流水** → 自助入口短指引  
3. **余额对不上** → 留证、转人工  
4. 可点快捷选项（≤5）

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 状态 | `account_flow`：`idle`／`awaiting_clarify` |
| 触发 | 查余额、余额、流水、账单明细、账户查询 等 |
| 分支 | 查余额／查流水／余额对不上／转人工 |
| 关键文件 | `account_dialogue.py` · `sessions.py` · 各对话 pack · `test_stage21_account.py` |

### 不做

- 真查余额／流水、接核心系统  
- 代客登录网银／App  

## 三、状态机

```text
idle → 问余额／流水／账户 → awaiting_clarify
  ├─ 查余额 → 短指引 → idle
  ├─ 查流水 → 短指引 → idle
  ├─ 余额对不上 → 短指引＋转人工 → idle
  └─ 转人工 → 建议转人工 → idle
```

## 话术原则

- 澄清一句口语；分支短答，不复读选项名  
- 不报具体金额、不承诺到账  

## 四、通过条件

1. 「查余额」／「流水」→ 短澄清 + 选项  
2. 「余额对不上」→ suggest 转人工  
3. pytest 相关用例通过  

## 五、验收（3050）

手打「查余额」走完路径。
