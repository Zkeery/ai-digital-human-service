## 分项结论

### 1. 多入口（A1）

- **做 2 个入口**：  
  - `entry_pilot_001` 通用金融咨询（默认）  
  - `entry_credit_001` 信用卡专窗  
- 差异先体现在：名称、欢迎语；换肤／Agent 在 A2 真正跟着入口变。  
- **客户页面不能选入口**；只有验收模式能选。

### 2. 换肤深度（A2）

- 不只浅色／深色。  
- 还要：**主色**、**Logo**（可先配本地或占位 URL，上传规范 A2 文档写清）。  
- 欢迎语按入口区分。

### 3. Agent 灰度（A2 生效）

- **全局总闸**：一关，所有入口都不用 Agent。  
- **每个入口自己的开关**：总闸打开时，还可按入口开／关。  
- **这些开关客户看不见**——只在验收模式或服务端配置里。

### 4. 统计分析（B1）

- 不做独立运营后台。  
- 只在 **3050 验收模式**加本地面板：会话量、转人工、Agent 使用、按入口汇总等。

### 5. RAG 首批知识（C1）

- 第一批只放：  
  - 网点／营业时间类公开样例  
  - 理财说明书公开摘要样例  
- 不把未脱敏工单、客户隐私原文塞进知识库。  
- RAG 可关；超时或未命中 → 回退现有规则话术，禁止编造政策。

## 刻意不做（本近程仍排除）

- 公网域名、现网 jtalk 挂载、正式登录隔离  
- 真 RTC／现网数字人 SDK（D2 另开；需测试凭证）  
- 接银行核心／柜面／真账务  
- 电商售后话术回归
