# 前端第 1 阶段 · 技术开发文档

> 只覆盖本阶段。不上线、不接真数字人引擎。

## 一、目标

在本机用前端走通：

试点入口 → 会话 →（引导）→ 数字人占位初始化 → 问答（FAQ／Agent）→ 推流／开始展示 → 超时降级提示 → 可选转人工／评价。

验收地址：**http://127.0.0.1:3050/**（后端仍 **8050**）。

## 二、通过条件

1. 上述主路径在桌面与约 390px 宽可走通  
2. mock 前端测试通过；后端回归 pytest 仍过  
3. 真实模型冒烟：沿用已冻结 D2（有 Key 时开 Agent 试一句即可）  
4. 前端无密钥；类型检查／生产构建通过  
5. README、项目状态、证据包已更新  

## 三、页面与状态

| 区域 | 行为 |
| --- | --- |
| 配置条 | 显示试点入口、Agent、llm_mock；可开关 Agent |
| 数字人区 | 形象选择、Room 状态、最近指令状态、降级横幅 |
| 对话区 | 历史气泡、输入发送 |
| 操作区 | 引导、推流、开始展示、检查同步／模拟降级、转人工、评价、特殊指令入口 |

会话状态：`idle` → `active` → `transferred`／结束。  
推流指令：`queued` → `started`／`skipped(降级)`。

## 四、API（已有，前端只调用）

- `GET/PUT /api/v1/config`
- `POST /api/v1/sessions` · `POST .../messages` · `POST .../guide`
- `POST .../digital-human/init|push|stream-started|check-sync|special`
- `POST .../fallback` · `POST .../transfer` · `POST .../rating`
- `GET .../history` · `GET /api/v1/themes`

错误体：`{"error":{"code","message"}}`。

## 五、目录

frontend/

## 六、启动

```bash
# 终端 1
./start.sh                 # 8050

# 终端 2
cd frontend && npm run dev # 3050
```

## 七、验收清单（产品经理）

1. 打开 3050，创建会话并展示引导  
2. 选形象并初始化  
3. 开关 Agent 各发一句  
4. 推流 → 开始展示  
5. 模拟／检查同步出现降级提示  
6. 转人工后不能再发消息  
7. 手机宽度再走一遍主路径
