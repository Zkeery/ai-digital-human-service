# 前端第 34 阶段 · 失败可重试与空态示例可点 · 技术开发文档

## 一、目标

对齐《产品设计文档》§5「初始化失败可重试」与可执行引导：

1. 开始咨询／发送失败时，顶栏错误条提供「重试」  
2. 空态示例问题可点击：未开始则自动开始并发送；咨询中直接发送  
3. **不改 API、不改会话协议、验收模式行为兼容**

## 二、范围

| 改 | 不改 |
| --- | --- |
| `bannerView`：`retry`、`emptyHintAction`、空态文案 | 后端错误码与接口 |
| `StatusBanner`：重试按钮 | 推流／Room 契约 |
| `SessionWorkspace`：`sendText`／开始后连带发送／重试 | 真 RTC、上线 |
| `ChatPanel`：示例问题按钮 | 多入口运营 |

## 三、验收

1. 3050 访客未开始：点空态「查余额」→ 自动开始并出现账户指引  
2. （可选）停后端再点「开始咨询」→ 红色条有「重试」；恢复后端后点重试可继续  
3. 发送失败后「重试」会再发同一句  
4. `npm test` 全过
