# 后端第 16 阶段 · 保修质保咨询 · 技术开发文档

> **线路：后端。** 不上线、不接真保修工单。  
> 前端开场加「保修」见 **前端第 15 阶段**。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。

## 一、目标（产品话）

用户问保修／质保时，先短问一句，再分流：

1. **在不在保** → 怎么看保修期  
2. **怎么申请** → 自助入口短指引  
3. **保修进度** → 哪里查／转人工  
4. 可点快捷选项  

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 状态 | `warranty_flow`：`idle`／`awaiting_clarify` |
| 触发 | 保修、质保、保修问题 等（其它多轮进行中不抢） |
| 分支 | 在不在保／怎么申请／保修进度／转人工 |
| 关键文件 | `warranty_dialogue.py` · `sessions.py` · 各对话 pack · `test_stage16_warranty.py` |

### 不做

- 真工单、寄修物流、改保修政策  

## 三、状态机

```text
idle → 问保修 → awaiting_clarify
  ├─ 在不在保 → 短指引 → idle
  ├─ 怎么申请 → 短指引 → idle
  ├─ 保修进度 → 短指引 → idle
  └─ 转人工 → 建议转人工 → idle
```

## 话术原则

- 澄清一句口语；分支短答，不复读选项名  

## 四、通过条件

1. 「保修」→ 短澄清 + 选项  
2. 「怎么申请」→ 短指引，不复读开头  
3. pytest 全绿

开场点「保修」走完路径。
