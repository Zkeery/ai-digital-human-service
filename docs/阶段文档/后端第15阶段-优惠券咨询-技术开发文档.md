# 后端第 15 阶段 · 优惠券咨询 · 技术开发文档

> **线路：后端。** 不上线、不查真券库存。  
> 前端开场加「优惠券」见 **前端第 14 阶段**。  
> 总览见 [咨询场景开发手册](咨询场景开发手册.md)。

## 一、目标（产品话）

用户问优惠券时，先短问一句，再用选项分流：

1. **用不了** → 核对门槛／叠加说明，不行转人工  
2. **找不到券** → 引导券包入口  
3. **过期或失效** → 说明规则，可转人工  
4. 可点快捷选项  

## 二、范围

### 做

| 项 | 说明 |
| --- | --- |
| 状态 | `coupon_flow`：`idle`／`awaiting_clarify` |
| 触发 | 优惠券、用券、折扣码 等（其它多轮进行中不抢） |
| 分支 | 用不了／找不到券／过期或失效／转人工 |
| 关键文件 | `coupon_dialogue.py` · `sessions.py` · 各对话 pack · `test_stage15_coupon.py` |

### 不做

- 发真券、改券规则、接促销系统  

## 三、状态机

```text
idle → 问优惠券 → awaiting_clarify
  ├─ 用不了 → 短指引 → idle
  ├─ 找不到券 → 短指引 → idle
  ├─ 过期或失效 → 短说明 → idle
  └─ 转人工 → 建议转人工 → idle
```

## 话术原则

- 澄清一句口语；分支短答，不复读选项名  

## 四、通过条件

1. 「优惠券」→ 短澄清 + 选项  
2. 「用不了」→ 短指引，不复读「用不了」开头  
3. pytest 全绿

开场点「优惠券」走完路径。
