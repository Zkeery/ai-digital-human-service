> **标注**：当前 AI 按 `tools/agent-blueprint` 手册分析，并调用离线 `select_components`；**未运行模型管线**，无独立模型审稿。

## 产品定位（一句话）

在 jtalk 数字人客服主链路上，增加可关闭的有界 AI 应答编排 Agent，并允许 C 端换肤；不重做会话与 RTC 底座。

## Step 1 需求拆解

| 维度 | 结论 | 状态 |
| --- | --- | --- |
| 目标 | 数字人形象完成咨询，失败可降级 | 明确 |
| 用户 | C 端咨询用户＋运营 | 明确 |
| 闭环 | 输入→分流唤醒→口播+图文→评价/转人工 | 明确 |
| 交付物 | 本批＝方案文档；未来＝会话体验 | 明确 |
| 边界 | 不自研引擎、不承诺上线、Agent 不执行转人工 | 明确 |
| 约束 | 人力有限；Room 限流；数据国内（待确认） | 部分待确认 |

## Step 2 Harness 五要素（领域骨架）

| 要素 | 落点 |
| --- | --- |
| 工具 | FAQ／配置只读、动作映射、转人工建议 |
| 知识 | 现网 FAQ、口播动作配置、特殊指令表 |
| 观察 | Room 状态、推流开始事件、2s 同步、评价 |
| 行动 | 经 jtalk 调数字人推流；Agent 只产出结构 |
| 权限 | 分流开关、Agent 开关、会话隔离、审计 |

| 组件 | 规则输出 | **项目采纳** | 理由 |

| s07/s08 | 二期 | **二期** | RAG／长会话压缩后置 |

## Step 4 七层架构（逻辑，非七服务）

```text
L7 体验层     jtalk C 端换肤 + 数字人蒙层
L6 编排层     固定工作流：分流→唤醒→应答→同步→结束
L5 认知层     NLP/FAQ + 可选 Agent compose（结构校验）
L4 工具层     配置/FAQ/动作映射（白名单）
L3 会话层     sid、数字人标记、历史有界
L2 媒体层     数字人服务端 + TTS/CV + RTC（外部）
L1 平台层     现网部署、密钥、审计、限流
```

**贯穿数据流**：用户话 → jtalk →（Agent?）→ NLP 图文 → 数字人推流 → 前端同步展示 → 会话落库。
